# Background music

Drop one `.mp3` here and the TV will loop it quietly under the sketch.
`boma.mp3` is used if present; otherwise the first `.mp3` in this directory.

With the directory empty the show simply runs without background music —
nothing to configure, nothing to disable.

Keep the file small. The browser streams it over the same Wi-Fi the robots use
for motion control, and a large file competes with them. The reference exhibit
at `../../Reachy_3/music2/` has re-encoded, exhibit-sized versions of its
tracks if you want a starting point.
